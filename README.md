# Motion IA para Windows

Kit de uso privado com seis skills para produção de motion, exemplos do curso e notas das 22 aulas.

1. Baixe o ZIP completo e extraia a pasta. Se recebeu acesso ao repositório privado, também pode cloná-lo.
2. Para produzir vídeos localmente, abra o Claude Code e entre com sua própria conta. Tenha internet na primeira instalação e permissão para instalar programas no Windows.
3. Na pasta extraída, abra `INSTALAR.cmd`. Escolha onde guardar os projetos e os vídeos prontos. O campo de assinatura é opcional.
4. Ao terminar a conferência, reabra o Claude Code na pasta dos projetos. Para começar, chame `/prompt-motion-graphics` e diga para quem é o vídeo, o que ele deve mostrar e onde será exibido.

Para o comercial de lata em 3D, execute `INSTALAR.cmd -ComBlender` no terminal da pasta. Se for usar só o chat, os pacotes da edição ZIP ficam em `chat/`. A tabela do guia indica quais estilos funcionam nele.
