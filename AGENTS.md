# Como usar este repositório

Para produzir um vídeo de uma nova marca, consulte `docs/06-projeto-novo.md` e crie uma pasta de projeto independente com `ferramentas/novo_projeto.py`. Use o briefing e os materiais desse projeto para conduzir a produção. As orientações criativas ficam em `modelo-projeto/AGENTS.md`.

Para manutenção do kit, faça mudanças nas ferramentas e no modelo de projeto. Preserve os arquivos de origem em `originais/`. Confira as duas cópias locais das skills em um projeto descartável antes de distribuir alterações do gerador.
