# Chat ou Claude Code?

O curso explica com a ideia de um restaurante: o **Claude** é o chef, o **prompt** é o seu pedido, a **skill** é a receita da casa (o prato que ele já testou mil vezes), a **referência** é a foto do prato que você quer, e a **prévia** é provar antes de servir. O **render** é o prato montado pra servir (o MP4 final).

O chef pode cozinhar em dois lugares:

| | **Chat** (claude.ai, app, celular) | **Claude Code** (no computador) |
|---|---|---|
| Onde roda | nos servidores da Anthropic: seu PC não esquenta | no seu PC: usa suas pastas, seu processador |
| Arquivos | você manda tudo a cada conversa (música, referência, efeitos) | ele lê direto das suas pastas (efeitos, músicas, fila de vídeos) |
| Prévia | quadros soltos do vídeo (imagens) | **HyperFrames**: player tipo editor de vídeo, com linha do tempo |
| Ajustes | costuma gerar o vídeo de novo do zero a cada ajuste (gasta mais) | mexe só na prévia; o render pesado é uma vez no fim (gasta menos) |
| Funciona em | qualquer lugar, até no celular | só no computador |
| Instalação | nenhuma (só subir os zips das skills) | o `INSTALAR.cmd` deste kit |
| Ponto fraco | mais gasto de uso, vai e volta de arquivos | o render pesa no PC (pode travar um pouco) |

**Recomendação do curso:** se tiver computador, use o **Claude Code**. Use o chat quando estiver no celular ou num PC fraco.
